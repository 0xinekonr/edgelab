## Phase 1：Java 云端最小服务

状态：当前学习路径下已完成主要目标。

范围：

- 初始化 Spring Boot 后端。
- 通过 Actuator 增加健康检查。
- 实现 `POST /api/v1/telemetry`。
- 增加请求参数校验。
- 增加基础统一错误响应。
- 增加聚焦后端测试。

学习重点：

- Spring Boot 工程结构。
- Maven 基础。
- Controller / Service 职责划分。
- DTO / record 请求和响应模型。
- API 版本号设计。
- MockMvc 和 JSON 格式合法性。

## Phase 3：第一次 Java / C++ 协作

状态：进行中，HTTP client 已有代码，main 接入及端到端验收待完成。

目标：

让 C++ 模拟器通过 HTTP 向 Java 后端发送遥测数据。

范围：

- 本地启动 Java 后端。
- C++ 生成遥测 JSON。
- C++ 调用 `POST /api/v1/telemetry`。
- 模拟器清晰打印响应状态。
- 明确 C++ JSON 与 Java DTO 的契约。

验收标准：

- Java 服务能成功接收 C++ 生成的遥测数据。
- C++ 模拟器能展示上报成功或失败。
- 后端测试仍通过。
